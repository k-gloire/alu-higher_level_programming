# SQL - Introduction

This project is part of the ALU Higher Level Programming curriculum. It
covers the basics of relational databases and SQL: creating and
dropping databases and tables, and using SELECT, INSERT, UPDATE, and
DELETE statements, including subqueries and aggregate functions.

## Files

| File | Description |
| --- | --- |
| `0-list_databases.sql` | Lists all databases |
| `1-create_database_if_missing.sql` | Creates the `hbtn_0c_0` database if missing |
| `2-remove_database.sql` | Deletes the `hbtn_0c_0` database if it exists |
| `3-list_tables.sql` | Lists all tables of a database |
| `4-first_table.sql` | Creates `first_table` (id, name) if missing |
| `5-full_table.sql` | Prints the full description of `first_table` |
| `6-list_values.sql` | Lists all rows of `first_table` |
| `7-insert_value.sql` | Inserts a new row into `first_table` |
| `8-count_89.sql` | Counts records with id = 89 in `first_table` |
| `9-full_creation.sql` | Creates `second_table` and inserts sample rows |
| `10-top_score.sql` | Lists all records of `second_table` by score, descending |
| `11-best_score.sql` | Lists records of `second_table` with score >= 10 |
| `12-no_cheating.sql` | Updates Bob's score to 10, by name only |
| `13-change_class.sql` | Removes records with score <= 5 |
| `14-average.sql` | Computes the average score |
| `15-groups.sql` | Counts records grouped by score |
| `16-no_link.sql` | Lists records with a non-null name, by score descending |
