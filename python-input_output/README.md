# Python - Input/Output

This project is part of the ALU Higher Level Programming curriculum. It
covers reading and writing files, the `with` statement, and JSON
serialization/deserialization in Python.

## Files

| File | Description |
| --- | --- |
| `0-read_file.py` | Reads a text file and prints its content |
| `1-write_file.py` | Writes text to a file, returns characters written |
| `2-append_write.py` | Appends text to a file, returns characters added |
| `3-to_json_string.py` | Returns the JSON string representation of an object |
| `4-from_json_string.py` | Returns the Python object represented by a JSON string |
| `5-save_to_json_file.py` | Writes an object to a file as JSON |
| `6-load_from_json_file.py` | Creates an object from a JSON file |
| `7-add_item.py` | Adds command line arguments to a JSON list file |
| `8-class_to_json.py` | Returns a serializable dict description of an object |
| `8-my_class.py` | Sample class used to demonstrate `8-class_to_json.py` |
| `9-student.py` | `Student` class with a `to_json` method |
| `10-student.py` | `Student` class with a filterable `to_json` method |
| `11-student.py` | `Student` class that can reload itself from JSON |
| `12-pascal_triangle.py` | Builds Pascal's triangle as a list of lists |
