# Python - Network #0

This project is part of the ALU Higher Level Programming curriculum. It
covers the basics of HTTP: URLs, requests, responses, headers, status
codes, and cookies, practiced through small `curl`-based Bash scripts.

## Files

| File | Description |
| --- | --- |
| `0-body_size.sh` | Displays the size, in bytes, of a response body |
| `1-body.sh` | Displays the body of a GET response, only on a 200 status |
| `2-delete.sh` | Sends a DELETE request and displays the response body |
| `3-methods.sh` | Displays all HTTP methods a server accepts for a URL |
| `4-header.sh` | Sends a GET request with a custom header and displays the body |
| `5-post_params.sh` | Sends a POST request with `email` and `subject` params |
