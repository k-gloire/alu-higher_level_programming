# Python - Network #1

This project is part of the ALU Higher Level Programming curriculum. It
covers fetching internet resources in Python using both `urllib` and
`requests`: GET/POST requests, reading response headers, handling
HTTP errors, and working with JSON APIs.

## Files

| File | Description |
| --- | --- |
| `0-hbtn_status.py` | Fetches the status page body (urllib) |
| `1-hbtn_header.py` | Displays the `X-Request-Id` header (urllib) |
| `2-post_email.py` | Sends a POST request with an email param (urllib) |
| `3-error_code.py` | Displays the body or HTTP error code (urllib) |
| `4-hbtn_status.py` | Fetches the status page body (requests) |
| `5-hbtn_header.py` | Displays the `X-Request-Id` header (requests) |
| `6-post_email.py` | Sends a POST request with an email param (requests) |
| `7-error_code.py` | Displays the body or HTTP error code (requests) |
| `8-json_api.py` | Searches for a user by letter via a JSON API |
| `10-my_github.py` | Displays a GitHub user's id via Basic Auth |
